# Python para ASIR — Guía Completa

Guía de estudio completa del libro **"Programación de Tareas de Sistema"**, adaptada para el ciclo formativo **ASIR (Administración de Sistemas Informáticos en Red)**.

## Contenido

| Capítulo | Tema |
|----------|------|
| Cap 1 | Introducción a Python — variables, tipos, operadores, comentarios |
| Cap 2 | Estructuras de control — if/elif/else, while, for, try/except |
| Cap 3 | Funciones y módulos — def, return, import, pip |
| Cap 4 | Listas, cadenas y otros tipos — listas, strings, tuplas, diccionarios |
| Cap 5 | Objetos y clases — POO, herencia, encapsulado |
| Cap 6 | Entrada/Salida — ficheros, CSV, properties, f-strings |
| Cap 7 | Administración del sistema — os, subprocess, sys.argv |
| Cap 8 | Tareas en red — sockets TCP, nmap, requests, BeautifulSoup |

## Uso

Abre `index.html` directamente en cualquier navegador. No requiere servidor ni instalación.

```bash
# Clonar y abrir
git clone https://github.com/TU_USUARIO/python-asir-guia
cd python-asir-guia
open index.html   # macOS
xdg-open index.html  # Linux
```

## Características

- Navegación lateral con resaltado automático por sección
- Bloques de código con sintaxis coloreada
