Introducción a Python

Lenguajes, algoritmos, tipos de datos, operadores y comentarios

¿Qué es Python?

Python es un lenguaje interpretado de alto nivel. Eso significa que tu código no se compila — lo lee un programa llamado intérprete que lo ejecuta línea a línea. Esto hace que el mismo código funcione en cualquier SO que tenga Python instalado.

Fue creado por Guido van Rossum a finales de los 80. El 20 de febrero de 1991 se publicó por primera vez. Hoy es uno de los lenguajes más usados del mundo: IA, scripts de admin, desarrollo web, automatización...

💡
Lenguaje interpretado vs compiladoLos lenguajes compilados (C, Java) se traducen a código máquina antes de ejecutarse. Python se ejecuta directamente por el intérprete. Más lento pero mucho más portable y rápido de escribir.

Instrucciones de selección — if / elif / else

Permiten ejecutar código solo si se cumple una condición. La tabulación es obligatoria — Python usa los espacios para saber qué pertenece a cada bloque.

PYTHON — if / else
a = 9
b = -1

if (a < b):
    print("El mayor es: " + str(b))
else:
    print("El mayor es: " + str(a))

print("FIN")  # esto se ejecuta siempre (fuera del if)
PYTHON — elif (múltiples condiciones)
producto = input("Introduce un alimento: ")

    print("Es una fruta")
elif producto == "tomate":
    print("Es una hortaliza")
elif producto == "pan":
    print("Es un cereal")
else:
    print("No sé lo que es")
💡
Regla de tabulaciónEn Python los bloques se definen por el nivel de sangría (tabulación). Todo lo que esté al mismo nivel de sangría pertenece al mismo bloque. No hay llaves {} como en otros lenguajes — la tabulación ES la estructura.
PYTHON — ifs anidados

def area(tipo, lado):
    if tipo == "cuadrado":

map() y filter()

PYTHON — map()
# map() aplica una función a cada elemento de la lista
def encierra(p):
    return "#" + p + "#"

nombres = ["ana", "luis", "marta"]
nueva = list(map(encierra, nombres))
print(nueva)    # → ['#ana#', '#luis#', '#marta#']
PYTHON — filter()
# filter() elimina los elementos donde la función devuelve False
def es_positivo(x):
    return x >= 0

numeros = [3, -1, 10, -23, 45]
positivos = list(filter(es_positivo, numeros))
print(positivos)    # → [3, 10, 45]
💡
map() y filter() devuelven un iterador, no una listaPor eso siempre hay que envolverlos con list() si quieres una lista normal. Sin el list() obtendrías un objeto que no puedes imprimir directamente.

Concepto de clase y objeto

Una clase es como una plantilla para crear nuevos tipos de datos. Un objeto es una instancia de esa clase — una variable creada a partir de ella.

PYTHON — definir clase con constructor
class Alumno:
    def __init__(self, nombre, edad):
        # self = referencia al objeto que se está creando
        self.nombre = nombre
        self.edad   = edad
        self.notas  = [0, 0, 0]   # siempre inicializa en cero

# Crear objetos
alumno1 = Alumno("Sergio", 40)
alumno2 = Alumno("Marta", 23)

# Acceder a atributos

print(alumno2.edad)      # → 23
💡
¿Qué es __init__?Es el constructor de la clase — el código que se ejecuta automáticamente cada vez que creas un objeto con Alumno(...). self es siempre el primer parámetro y representa al propio objeto que se está creando.

Métodos y atributos

PYTHON — métodos
class Alumno:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad   = edad
        self.notas  = [0, 0, 0]

    def es_mayor_edad(self):
        return self.edad >= 18           # devuelve True/False

    def nota_media(self):
        return (sum(self.notas)) / 3

    def nombre_formal(self, titulo):
        return titulo + " " + self.nombre

a = Alumno("Marta", 38)
a.notas = [7, 8, 9]
print(a.es_mayor_edad())          # → True
print(a.nota_media())              # → 8.0
print(a.nombre_formal("Doña"))    # → "Doña Marta"

Encapsulado: getters y setters

Lo correcto es no acceder a los atributos directamente desde fuera. Se usan métodos get_ para leer y set_ para modificar. Los atributos privados llevan __ al principio.

PYTHON — getters, setters y atributos privados
class Alumno:
    def __init__(self, nombre, edad):
        self.__nombre = nombre   # __ = privado (no accesible directo)
        self.__edad   = edad

    # Getter: leer el valor
    def get_nombre(self):
        return self.__nombre

    # Setter: modificar el valor
    def set_nombre(self, n):
        self.__nombre = n

    def get_edad(self):
        return self.__edad

a = Alumno("Iván", 22)
print(a.get_nombre())   # → "Iván"
a.set_nombre("Ivan R.")
# a.__nombre  ← daría AttributeError (privado)

Herencia

La herencia permite crear una clase basada en otra. La clase hija hereda todos los atributos y métodos de la clase padre, y puede añadir los suyos propios.

PYTHON — herencia con super()
class Persona:
    def __init__(self, nombre, edad):
        self.__nombre = nombre
        self.__edad   = edad

    def get_nombre(self):
        return self.__nombre

    def get_edad(self):
        return self.__edad


class Alumno(Persona):       # hereda de Persona
    def __init__(self, nombre, edad):
        super().__init__(nombre, edad)  # llama al __init__ del padre
        self.notas = [0, 0, 0]

    def nota_media(self):
        return sum(self.notas) / 3


p1 = Persona("Sergio", 40)
a1 = Alumno("Marta", 38)

print(p1.get_nombre())  # → "Sergio"
print(a1.get_nombre())  # → "Marta"  (heredado de Persona)
a1.notas = [8, 9, 7]
print(a1.nota_media())  # → 8.0
🔑
super() — llamar al padresuper().__init__(...) ejecuta el constructor de la clase padre. Sin esto, el hijo no heredaría los atributos del padre y tendrías que reescribir todo. Siempre llámalo al principio del __init__ del hijo.

Lectura y escritura de ficheros

Trabajar con ficheros en Python siempre sigue el mismo flujo de 3 pasos.

1
Abrir — open(ruta, modo)

Dile al SO qué fichero quieres y qué vas a hacer: leer ("r"), escribir ("w") o añadir ("a").

2
Leer o escribir

Usa read(), readlines(), write() o writelines().

3
Cerrar — close()

Obligatorio. El SO vuelca los datos al disco aquí. Sin close() puedes perder datos.

ModoQué hace¿Crea si no existe?¿Borra lo anterior?
"r"Solo lecturaDa error—
"r+"Lectura y escrituraDa errorNo
"w"Escritura desde ceroSíSí, lo vacía
"a"Añadir al final (append)SíNo, añade detrás
⚠️
"w" vs "a" — diferencia críticaCon "w" cada apertura borra todo el contenido anterior. Con "a" el contenido previo se mantiene y añades al final. Para logs y registros usa siempre "a".
PYTHON — escribir en fichero
fichero = open("nombres.txt", "w")

while True:
    nombre = input("Nombre (vacío para salir): ")
    if len(nombre) == 0:
        break
    fichero.write(nombre + "\n")   # \n = salto de línea

fichero.close()   # ¡Siempre cerrar!
PYTHON — leer fichero
fichero = open("nombres.txt", "r")
lineas = fichero.readlines()   # devuelve lista de líneas

for linea in lineas:
    print(linea.strip())   # strip() quita el \n del final

fichero.close()

#      nombre;apellido;edad;ev1;ev2;ev3;faltas

fichero = open("alumnos.csv")

os.walk() — recorrer árbol completo

En cada iteración devuelve 3 cosas: directorio actual, lista de subdirectorios, lista de ficheros.

PYTHON — os.walk()
import os

# Listar todos los ficheros con su ruta completa
for actual, subdirs, ficheros in os.walk("/home/ivan"):
    for f in ficheros:
        print(os.path.join(actual, f))

# Distinguir ficheros (F) y directorios (D)
for actual, subdirs, ficheros in os.walk("/home/ivan"):
    for hijo in subdirs + ficheros:
        ruta = os.path.join(actual, hijo)
        if os.path.isdir(ruta):
            print("D " + ruta)
        else:
            print("F " + ruta)

text=TrueDevuelve strings en vez de bytes

timeout=NMata el proceso si tarda más de N segundos

Modelo cliente/servidor — Sockets TCP

El modelo cliente/servidor es la base de toda comunicación en red:

  • El servidor arranca, se vincula a un puerto y espera conexiones.
  • El cliente conoce la IP y el puerto del servidor y se conecta.
  • Una vez conectados, ambos pueden enviar y recibir datos en cualquier orden.
⚠️
Error más común con socketsPensar que solo el cliente envía y el servidor recibe. Es falso — ambos tienen send() y recv() y pueden usarlos cuando quieran. La comunicación es completamente bidireccional.
ConstanteProtocoloCuándo usarla
socket.AF_INETIPv4Siempre — es la familia de direcciones estándar
socket.SOCK_STREAMTCPCuando necesitas fiabilidad (los datos llegan completos y en orden)
socket.SOCK_DGRAMUDPCuando prefieres velocidad y no importa perder algún paquete

Cliente TCP completo

PYTHON — CLIENTE TCP
import socket

# 1. Crear el socket TCP + IPv4
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. Conectarse al servidor (IP, puerto)
s.connect(("127.0.0.1", 5000))

# 3. Enviar datos — encode() convierte string → bytes
s.send("Hola servidor!".encode())

# 4. Recibir respuesta — decode() convierte bytes → string
respuesta = s.recv(1024)
print("Respuesta:", respuesta.decode())

# 5. Cerrar
s.close()

Servidor TCP — un solo cliente

PYTHON — SERVIDOR TCP (un cliente)
import socket

# 1. Crear socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)

# 2. Vincular a un puerto (bind)
s.bind(("localhost", 5000))

# 3. Activar modo escucha
s.listen()
print("Esperando conexiones...")

# 4. Aceptar una conexión — bloquea hasta que alguien se conecte
cliente_socket, direccion = s.accept()
print("Conexión de:", direccion)

# 5. Recibir datos
datos = cliente_socket.recv(1024)
print("Recibido:", datos.decode())

# 6. Responder (opcional)
cliente_socket.send("Recibido!".encode())

# 7. Cerrar sockets
cliente_socket.close()
s.close()

Servidor TCP — múltiples clientes (bucle)

PYTHON — SERVIDOR TCP (múltiples clientes)
import socket

s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.bind(("localhost", 5000))
s.listen()
print("Servidor listo...")

while True:                          # bucle infinito
    cli, dir = s.accept()
    print("Conexión de:", dir)

    datos = cli.recv(1024)
    print("Datos:", datos.decode())

    cli.close()   # cerramos solo el socket del cliente
    print("Esperando otro cliente...")

# s.close() solo cuando quieras apagar el servidor definitivamente

Monitorización de la red — python-nmap

La librería python-nmap permite hacer escaneos de puertos y detectar servicios en red desde Python.

PYTHON — escaneo de puertos
import nmap

def scan_ports(target):
    nm = nmap.PortScanner()
    nm.scan(target, arguments='-p 1-1000')  # puertos 1 a 1000

    for host in nm.all_hosts():
        print(f"Host: {host} — Estado: {nm[host].state()}")

        for proto in nm[host].all_protocols():
            puertos = nm[host][proto].keys()
            for puerto in puertos:
                estado = nm[host][proto][puerto]['state']
                print(f"  Puerto {puerto}/{proto}: {estado}")

scan_ports("127.0.0.1")

import requests
